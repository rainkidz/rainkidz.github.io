Frequently Asked Questions

Clear technical answers on security, APK sideloading, updates, and studio architecture.

Safety & Trust

Are these apps safe to install?

Yes. Every APK here is built and released by rainkidz, hosted on GitHub Releases, and each app page shows a SHA-256 fingerprint so you can verify the file after downloading. Apps are free and contain ads (Google AdMob); no account is required. No analytics or crash-reporting SDKs are included.

Why does Google Play Protect show a warning?

Play Protect warns about any app that is not installed through the Play Store. This is normal for sideloaded apps. Review the SHA-256 fingerprint on the app page, then choose to install anyway.

Toyota Parts Price needs a login?

Yes. Toyota Parts Price is an internal app for the TASTI network — login with a registered account is required. For credentials and authorization, contact support@tasti.id.

Installation

How do I install an APK?
  1. Pick an app and tap Download APK.
  2. Open the downloaded APK file.
  3. If a warning appears, enable "Install unknown apps" for your browser or file manager.
  4. Tap Install, done.
How do I verify the SHA-256 checksum?

Copy the fingerprint from the app page (the Copy Hash button), then hash the downloaded file and compare:

Windows: certutil -hashfile app.apk SHA256 Linux: sha256sum app.apk

The output must match the fingerprint exactly.

Updates & Versions

How do updates work?

It depends on the app. Tubenime checks for new versions in Settings and notifies you; tap Update to grab the new APK from GitHub Releases. Toyota Parts Price updates automatically via the Play Store. For Wispmail, check the catalog's Version Archive for new releases. Apps outside Google Play cannot auto-update via the Play Store.

Where can I find older versions?

Open an app's detail page — the Version Archive table lists releases with direct download links. Older builds are also on GitHub Releases.
